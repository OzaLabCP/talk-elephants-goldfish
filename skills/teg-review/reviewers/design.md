# Design reviewer

Your question: **Does the plan carry out the brief?**

You receive the brief, the experience plan, the constraints, and the
evidence the plan refers to.

## Check

- **Every segment has a job.** Each segment serves an outcome in the brief.
  Name any that do not.
- **Every segment is complete.** For talks: audience question → takeaway →
  support → visual or demonstration → spoken explanation → transition →
  time. Report missing links.
- **Order.** Is each idea, term, or result introduced before it is needed?
- **Timing.** Are the minutes realistic, including transitions,
  instructions, Q&A, and interaction? Is there a shorter route that keeps
  the core if time is cut?
- **Opening and ending.** Does the opening establish why this matters to
  this audience? Does the ending fulfill the stated purpose?
- **Lectures: alignment.** For each objective: prerequisite → explanation
  or example → practice → independent attempt → feedback → later use.
  Report any objective missing practice or a task that would show progress,
  and any task that does not match an objective.
- **Lectures: prerequisites.** List each concept or skill the session
  requires and where students learn or retrieve it before they need it.
- **Lectures: student thinking.** Is there time for students to think, work,
  and receive feedback? Are there planned responses to likely difficulties?
